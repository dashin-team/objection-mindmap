# 夥伴投稿：Google 試算表設定

夥伴沒有 GitHub 帳號也可以投稿。表單會把內容送到你的 Google 試算表；你勾了審核，網站才會顯示，並標上「夥伴分享」和投稿人的名字。

還沒設定完成時，網站一樣能用。投稿表會改成一段文字，夥伴複製後貼到 LINE 給你。

## 1. 建立試算表

1. 打開 [Google 試算表](https://sheets.google.com)，新增一份空白試算表。
2. 名稱可取「問句王投稿」。分頁名稱不用先改，程式第一次收到投稿時會自己建立分頁「投稿」。

## 2. 貼上程式

1. 在試算表選單選 **擴充功能 → Apps Script**。
2. 把預設的程式全部刪除，改貼本資料夾的 `Code.gs`。
3. 按儲存。專案名稱可取「問句王投稿」。

請從試算表裡開啟 Apps Script，不要另外開一個獨立的指令碼專案。這樣程式才寫得進這份試算表。

## 3. 部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 類型選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 具有存取權的使用者：**任何人**
4. 按部署。第一次會要求授權，選你的 Google 帳號，允許存取試算表。
5. 複製最後的網址。它長這樣：

   `https://script.google.com/macros/s/……/exec`

6. 用瀏覽器打開這個網址，應該看到：

   `{"ok":true,"items":[]}`

若看到要求登入，代表存取權不是「任何人」。請重新部署，存取權改成任何人。

## 4. 把網址寫進網站

編輯 `js/config.js`：

```js
window.APP_CONFIG = {
  SUBMIT_ENDPOINT: "https://script.google.com/macros/s/……/exec",
};
```

只放 `/exec` 網址，前後不要空白。存檔後推上 `main`。GitHub Pages 更新後，網站會讀取已審核的投稿，表單也會直接送出。

## 5. 審核

投稿會出現在「投稿」分頁，`approved` 是核取方塊，預設未勾。

確認內容適合給夥伴用之後，勾選那一列的 `approved`。重新整理網站，就會看到「夥伴分享」。

不要改第一列的欄位名稱。欄位依序是：

`id`、`createdAt`、`type`、`submitter`、`bank`、`category`、`title`、`objectionId`、`nodePath`、`clientSays`、`followUp`、`dimension`、`question`、`C`、`A`、`R`、`approved`、`note`

- `type` 為 `new_objection`：一題新的反對問題。
- `type` 為 `branch`：加在某一題、某一句下面的客戶回答和追問。`nodePath` 空白表示加在主問句下面，`0/1` 表示第一個回答裡的第二個分支。
- `note` 留給你自己註記，網站不會顯示。

取消勾選，這則就會從網站消失。刪除該列也可以。

## 6. 改過程式之後

Apps Script 改完要重新部署才會生效：**部署 → 管理部署作業 → 鉛筆 → 版本選「新版本」→ 部署**。網址通常不會變，`config.js` 不用再改。

## 隱私

試算表裡是夥伴的名字和問句，不是客戶個資。表單也請夥伴不要填客戶的姓名、電話。筆記（五宮格）只存在夥伴自己的手機，不會進這張表。

若網站連不上試算表，投稿頁會改顯示可複製的文字，貼到 LINE 就不會遺失。
